# Código de Conduta

Participantes devem manter comunicação respeitosa, técnica e inclusiva. Assédio, discriminação,
ameaças, exposição de dados pessoais e ataques pessoais não serão tolerados. Incidentes devem ser
relatados privadamente aos mantenedores, que poderão advertir, moderar ou excluir participantes de
forma proporcional.
