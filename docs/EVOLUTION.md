# Regra de evolução pós-1.0

Cloud, se adotada no futuro, será adapter opcional para sincronização, backup ou colaboração. O
produto local permanece o centro da arquitetura.

Antes de implementar uma ideia, a proposta deve responder:

1. Ela trabalha com documentos?
2. Ela se integra ao Document Graph?
3. Ela pode ser uma Tool?
4. Quick, Studio ou ambos?
5. Qual Artifact recebe?
6. Qual Artifact produz?
7. Ela precisa de rede?
8. Ela pode rodar localmente?
9. Qual é a licença da engine?
10. Ela melhora o NexoHub ou apenas aumenta o número de cards?

Uma resposta afirmativa apenas ao aumento de cards é fundamento para rejeitar a proposta.
