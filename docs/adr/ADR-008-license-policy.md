# ADR-008: Política de licenças

- **Status:** aceito
- **Contexto:** distribuição open source exige compatibilidade jurídica previsível.
- **Decisão:** código do NexoHub usa MPL-2.0; dependências preferenciais são MIT, Apache-2.0, BSD e
  MPL-2.0. GPL/AGPL no binário distribuído exige decisão arquitetural e jurídica explícita.
- **Consequências:** toda dependência é inventariada e avaliada por licença, manutenção, tamanho,
  segurança, necessidade e alternativas.
